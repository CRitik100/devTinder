# devTinder — Backend

devTinder is a developer-focused platform where people can discover other developers, send connection requests, and start conversations. This repository contains the backend API that powers user accounts, profiles, connection flow, and real-time chat.

If you want the frontend, check out [devTinderWeb](https://github.com/CRitik100/devTinderWeb).

## Features

- Developer profiles and authentication
- Connection requests between users
- Real-time chat using Socket.IO
- Email notifications for key events

## Tech stack

- Node.js + Express
- MongoDB + Mongoose
- JWT authentication
- Socket.IO
- Amazon SES
